# Kontrakan Cerdas

Pengembangan fitur Artificial Intelligence untuk sistem Kontrakan Cerdas.

## AI Features

- Intent Classification
- Generative AI (Gemini API)
- Retrieval-Augmented Generation (RAG)
- Complaint Classification

## Project Structure

- `ml-training/` : Dataset, preprocessing, dan training model.
- `ai-service/` : Backend AI menggunakan FastAPI.

## Main Quest

Pengembangan model Intent Classifier untuk mengidentifikasi maksud pertanyaan penyewa melalui WhatsApp menggunakan Bahasa Indonesia, Sunda, dan campuran.
